Preloaded /mipmap/70 → WebGL2

Preloads /mipmap/70 once when this page opens. Each benchmark run creates a fresh ImageDecoder, uploads decoded frames to a texture array, generates GPU mipmaps, and draws every layer. Network time is excluded from measured runs.

The server currently ignores the requested count and returns the whole library. This benchmark uses the actual animation frame count. Download completes before decoding so texture allocation does not assume a fixed number of frames.

One warmup is excluded. The preload uses cache: no-store. Each run copies the encoded bytes before starting its timer, so byte-copy time is also excluded. Decoder setup is included in elapsed milestones but not summed decode waits. This is not a streaming benchmark. Upload measures CPU submission, not GPU execution. GPU-complete includes a fence after mipmaps and drawing; polling adds latency. No gl.finish() in the measured path.

Serve this directory over localhost; ImageDecoder requires a supported browser and secure context.
