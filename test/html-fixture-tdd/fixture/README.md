# Rendering test fixtures

`library/` is a synthetic lfs-booru library: three small PNG images, matching WebP
thumbnails, and a fixed NDJSON add-event shard. Media filenames are SHA-256 hashes
of their contents. No external images, Git repository, or LFS server are needed.

The six `*.expected.html` files are renderer output for that library: image card
and inspector for image 1, and a photo grid, gallery content, and gallery page
listing images 1 and 2 of 3, sorted by `addedAt`. Cards inside the grid are
rendered with `ItemCard` rather than escaped HTML strings.

Generated by `../lfs-booru` at HEAD `99edd34d6e97e71d891179ad9f3ce0cc927d7ace`.
The generator has been removed; these files are the baseline to reproduce in Odin.
